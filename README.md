# Nexa

Nexa is a simple digital gateway designed to help Nigerians discover
useful services, businesses, opportunities, and learning resources.

## Nexa v1

Nexa v1 is a front-end prototype built with:

- HTML
- CSS
- JavaScript
- LocalStorage
- Browser Geolocation API

## Features

- Search
- Category filtering
- Services
- Businesses
- Opportunities
- Learning resources
- Location detection
- Nearby results
- Distance calculation
- Saved items
- Details modal
- Responsive design
- Accessibility improvements

## Running Locally

Open `index.html` in a browser or run the project using a local development server.
